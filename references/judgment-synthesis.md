# Judgment Synthesis

## 目的

Judgment Synthesis 把已通过稳健性审查的数据事实放回用户确认的决策语境。它不是 summary：summary 缩短事实，synthesis 说明事实合起来改变了什么判断。

## 判断链

```text
Final findings
→ 它们共同回答哪个 decision question
→ 哪些是直接事实，哪些是可支持解释，哪些只是候选解释
→ 相对 current strategy / hypothesis 改变了什么
→ 直接行动、先试验、补数据，还是不行动
→ 反证、替代解释与限制
→ 编写可反驳判断句
→ Why-so 回溯
```

## 行动状态

- `direct`：证据和语境足以支持当前范围的选择或调整。
- `test-first`：数据支持一个有价值的方向，但机制、效果或外推需验证。
- `data-needed`：现有证据不能裁决，明确还需要什么。
- `no-action`：事实增加理解但不改变当前决策。

不得把“每个章节都必须有行动”当成质量标准。

## 判断句编辑

合格判断句必须：

1. 是有主语和谓语的完整句子。
2. 写清业务对象、比较基准与决策含义。
3. 可被证据反驳，不是“存在机会、值得关注、显示出错位”。
4. 去掉数字后仍能理解判断；去掉比喻和形容词后仍有决策意义。
5. 已知业务对象时，不让分析层、类群标签或字段名充当主语。
6. 无因果识别时不使用“导致、驱动、带来、促进”。

“高地、沉默多数、以小博大、长尾铺量、破圈入口、爆文公式、规模与贡献错位”是审稿触发器，不是完整禁词表。出现时必须追问：去掉这个包装词，业务判断究竟是什么？

## 证据语气

- Descriptive：“在本样本/时间窗口中更高、更集中、同步变化”。
- Associational：“与…相关/共现，可能解释包括…”。
- Causal：只在实验或足够识别设计下使用“导致/产生增量”。

统计显著不等于决策重要；符合旧判断但显著提高置信度的结果也可以是有价值的判断，不以“新奇/反常识”为洞察门槛。

## Plain-language review

- 读者不知道字段名时能否理解？
- 是否只是把“高/低/占比/排名”换成咨询词？
- 业务对象和比较基准是否明确？
- 是否把观察性关联写成机制或策略效果？
- 判断是否回答 CP0 问题，还是只回答数据表里有什么？
- 行动级别是否超过证据和语境？

## 差例与合格改写

```text
差：内容组合长什么样：规模与互动贡献的错位。

合格：产品使用场景类内容在样本中只占少数，却贡献了更高比例的互动；
这一结果支持将扩大场景化内容作为待验证方向，但尚不证明扩量后仍能保持同等互动率。
```

## 验收

自动检查只能发现字段缺失、断链、一些因果越界词和包装词。判断是否真正改变决策，必须用 paired Eval 和人工盲评验收。
